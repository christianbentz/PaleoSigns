\hypertarget{description}{%
\section{Description}\label{description}}

This file enables randomization of sign strings which occur on different
parts of an object (indicated by underscore `\_'). We do not know the
order of these strings (if any), hence they are randomized. In the case
of the Magdalenian teeth of the Saint-Germain-la-Rivière burial, we
consider them as one assemblage, that is, we concatenate them by also
using underscores.
