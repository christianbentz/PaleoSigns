06.03.2025

Description

This file provides code to estimate to what extend randomized sign sequences deviate from the original sequences given in SignBase in terms of the entropy rates. This is necessary since the order of strings into sequences (strings are delimited by underscore in SignBase) is arbitrary. Note that randomization does only affect the entropy rate calculated over the sign tokens in sequences. All the other measures (TTR, unigram entropy, repetition measure) yield the same values for randomized sequences.

Correlation

cor.value <- round(cor(sign.data$hrate.chars, sign.data$hrate.chars.random, 
                       method = "pearson"), digits = 2)
cor.pvalue <- round(cor.test(sign.data$hrate.chars, sign.data$hrate.chars.random, 
                             method = "pearson")$p.value, digits = 2)

Plot

Entropy rate

Entropy rate for the original versus randomized sequences (i.e. strings of sign tokens where randomized).

hrate.random.plot <- ggplot(sign.data, aes(x = hrate.chars, y =  hrate.chars.random)) + 
  geom_point(aes(size = num.tokens), alpha = 0.3) +
  geom_smooth(method = "loess") +
  theme(legend.position = c(.8, .25)) +
  annotate("text", x = c(0.5,0.5,0.5), y = c(1.7,1.6,1.5), 
           label = c(paste("r = ", cor.value, sep =""), 
                     "p-value < 0.0001",
                     paste("n = ", sample.size, sep ="")), size = 4) +
  labs(x = " Entropy rate for tokens (original)", 
       y = "Entropy rate for tokens (randomized)") +
  guides(size = guide_legend(title="No. of signs"))
hrate.random.plot <- ggMarginal(hrate.random.plot,
                                  type = "density")
