Randomization Analyses

Description

This file provides code to estimate to what extend randomized sign sequences deviate from the original sequences given in SignBase in terms of the quantitative features. This is necessary since the order of strings into sequences (strings are delimited by underscore in SignBase) is arbitrary. Note that randomization does only affect the entropy rate calculated over the sign characters in sequences. All the other measures (TTR, unigram entropy, repetition measure) yield the same values for randomized sequences.

Plot

Entropy rate

Entropy rate for the original versus randomized sequences (i.e. strings of sign characters where randomized).

hrate.random.plot <- ggplot(sign.data, aes(x = hrate.chars, y =  hrate.chars.random)) + 
  geom_point(aes(size = num.char), alpha = 0.3) +
  geom_smooth(method = "loess") +
  theme(legend.position = c(.8, .25)) +
  labs(x = " Entropy rate for characters (original)", y = "Entropy rate for characters (randomized)")
hrate.random.plot <- ggMarginal(hrate.random.plot,
